# Get started

Epistoria is not available for public download. These instructions apply to an installed personal
beta build.

## Create your notebook

1. Open Epistoria.
2. Select **Create my private notebook**.
3. Write down the account ID and all 24 recovery words.
4. Keep at least two offline copies in different secure locations.
5. Select **Continue to verification**.
6. Enter the three requested words from your written copy.
7. Select **Open Epistoria**.

Do not photograph the recovery words or store them in chat, email, or a cloud note. Anyone with
the account ID and recovery words can access a recovered copy of the notebook data.

## Create your first note

1. Open **Today**.
2. Select **Quick note**.
3. Open the page menu beside the note title.
4. Choose A4, US Letter, or Infinite canvas.
5. Choose Plain, Ruled, Grid, or Dotted paper.
6. Select **Pen** to write with Apple Pencil.
7. Select **Text** to add typed text.
8. Select **Image** to add an image.

The note saves on the iPad without requiring a server.

## Import a PDF

1. Open **Today** or a course.
2. Select **Import PDF**.
3. Choose one or more PDF files.
4. Wait for the import to finish.
5. Open a PDF to read it and add page annotations.

Epistoria keeps the imported original unchanged.

## Start a study session

1. Open **Today**.
2. Select **Start a session**.
3. Enter the study intention.
4. Add or open notes and resources during the session.
5. End the session when finished.

If trusted processing is configured, you can request a cited digest after the session.

## Understand status

| Status | Meaning |
|---|---|
| **Saving…** | The current change has not finished saving on the iPad. |
| **Saved** | The change is stored on the iPad. |
| **Waiting to sync** | An encrypted copy is waiting for the optional private server. |
| **Syncing** | The app is transferring encrypted changes. |
| **Synced** | The private server acknowledged the encrypted changes. |
| **Conflict** | Another version is available for review. |

A local saved state is not the same as another synchronized copy.
