# Epistoria documentation

Epistoria is a personal iPad notebook for learning and research. It combines handwriting, typed
text, images, PDFs, annotations, study sessions, search, and optional assistance in one place.

The project started because I needed a notebook that could adapt to whichever subject I am studying. It is a personal project.

## Product status

Epistoria is in personal beta development. It is not available for public download. The current build is intended for its owner and test devices.

Do not use a beta build as the only copy of important material. Keep the recovery information and
an independent copy of important source files.
