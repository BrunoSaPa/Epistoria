# Roadmap

This roadmap describes intended product direction. It is not a delivery schedule. Priorities can
change after personal use and beta testing.

## Before broader use

- Complete physical iPad testing for Pencil, large notes, large PDFs, accessibility, orientation,
  multitasking, keyboard, and pointer input.
- Complete two-device synchronization and concurrent-version testing.
- Complete fresh-device recovery and independent backup drills.
- Complete private installation and update testing.
- Decide whether readable-only export is acceptable for the first beta or add import support.

## Portability and file access

- Import a validated Epistoria export into a clean installation.
- Download selected or all restored files for offline use.
- Improve archive and restore support for resources and collections.
- Add a persistent Trash with a clear retention policy.

## Notebook tools

- Add page thumbnails, insertion, duplication, deletion with recovery, and ordering to the
  continuous fixed-page document.
- Add direct printing and PDF page-range and layout options.
- Add image crop and mask tools.
- Add editing for an existing shape's style, connectors, snapping, and alignment guides.
- Evaluate handwriting recognition, handwritten-math recognition, equation layout, LaTeX input,
  and graphing after Pencil testing.

## Review and learning

The learning system will be added in stages after the current data-safety checks are complete.

1. Add study goals, unresolved questions, manual flashcards, saved practice tests, and complete
   attempt history.
2. Store accepted cards, tests, answers, results, and review history as protected notebook data.
   Keep them available offline and include them in synchronization, recovery, and export.
3. Let the user request a test for a subject inside a selected notebook, course, session, or source
   range.
4. Add Quick check, Comprehensive, and Custom test modes. Comprehensive tests will show the
   detected topics before generation, cover every supported topic, use broader questions when
   appropriate, and report missing material or time limits instead of silently omitting content.
5. Generate draft flashcards and tests. Every generated answer will link to the material that
   supports it and will require review.
6. Add test history with the exact questions, responses, score, incorrect answers, feedback, and
   source links. Retaking a full test or only missed material will create a new result and preserve
   the old one.
7. Add a **Study next** queue that considers goals, deadlines, due reviews, practice results,
   confidence, unresolved questions, source coverage, and recent unfinished work.
8. Explain every recommendation and allow the user to start, pin, snooze, dismiss, or correct it.
9. Add optional feedback for written answers. Show the grading guide and allow a score override.
10. Add a proactive mode for selected material. The user will choose the allowed material, tasks,
   frequency, expiration, and spending limit, and can pause it at any time.
11. Add a weekly review for recent study, difficult material, unresolved questions, upcoming work,
   and recommended next actions.
12. Evaluate optional local semantic search and evidence-backed concept suggestions.

Opening the app will not by itself send notebook content for processing. Review scheduling and the
base daily queue will run on the iPad without paid processing.

## Companion experiences

- Add an iPhone quick-capture option.
- Add a simple Mac status view for processing and synchronization health.

## Outside the current scope

The personal project does not currently plan collaboration, public sharing, social features,
subscriptions, billing, or organization administration.
